# Speech fixture

`SpeechFixture.aiff` is a local macOS text-to-speech sample generated during Snow Globe development using Jamie (Premium). It contains spoken test sentences, with syllables and pauses for reproducible envelope and signed-waveform tests. Tests read this recording; they do not invoke speech synthesis or require the voice to be installed. It is a test resource, not bundled with the SnowGlobe library or demo app.
